Tickets on the chain.

Create an event. Sell tickets in KAS. Anyone holding a ticket gets in.

Tickets live on Kaspa — so they can't be copied, and the door can't be fooled.

Looking around needs no wallet.

For agents

Every flow — deploy an event, buy a ticket, list or delist it, check in at the door — works over the HTTP API with no browser. Identity is a wallet signature. No browser is required.
